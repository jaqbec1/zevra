# Zevra personal evaluation

Language for importing a personal archive and evaluating whether material is worth the user's time.

## Language

**Notes source**:
A collection of notes explicitly selected by the user as the scope of an import. Its boundary is independent of where a Base file is stored.
_Avoid_: inferred vault, Base location

**Base filter**:
The global conditions and selected view conditions from an Obsidian Base that select notes within a notes source.
_Avoid_: source folder, archive content

**Archive candidate**:
An imported material available for review, without an implied assessment of its value.
_Avoid_: positive example, recommendation

**Rated example**:
A material explicitly judged worthwhile or not worthwhile by the user, providing evidence for personal evaluation.
_Avoid_: saved item, consumed item

**Current goal**:
An intention stated by the user about what they want to achieve now.
_Avoid_: browsing history, inferred preference
